# Views

Every figure is an SVG (editable; a browser or Inkscape opens it) with a PNG render. They are generated from one source so names and notation stay identical across views. Notation: the ID on the tab of each element links it to the documents; teal is inside DH-05, plum is people, grey is outside DH-05, dashed means designed but not built, the saffron highlight marks the critical path of the activation gate (AD-01).
